## CRITICAL — instrument-invalidating

### C1. "DonuAndDeca" is not a registry key → Act-3 boss fight spawns ZERO enemies → instant free win
- `run_loop.py` `ACT3_BOSS_ENCOUNTERS = [["DonuAndDeca"], ...]` but
  `register_act2_act3` registers `"Donu"` and `"Deca"` separately.
- `spawn_enemies` does `cls = ENEMY_REGISTRY.get(eid); if cls:` — **silently skips**
  unknown ids → returns `[]`.
- `is_combat_over` with an empty enemy list: `all(e.hp <= 0 for e in [])` is `True`
  → `"win"` on the first check, before a single LLM call or card play.
- **Proof (seed 42):** `DonuAndDeca spawned: 0 enemies` / `combat outcome with
  0 enemies: win`.
- **Impact:** 1/3 of Act-3 boss rolls are auto-wins → directly inflates `--acts 3`
  survival/progress. Would have poisoned the M3b appendix probe.
- **Fix (3 layers, all required):**
  1. Table entry → `["Donu", "Deca"]` (the fight is both together, as in the real game).
  2. `spawn_enemies`: unknown id → `raise ValueError(f"Unknown enemy id: {eid}")`
     (silent skip masked this for months).
  3. `start_combat`: `raise ValueError("start_combat with no enemies")` on an empty
     list (defense in depth; empty combat is never meaningful).
- **Regression tests:** (a) executable invariant — every id in all 9 encounter tables
  resolves in the registry (this test alone would have caught C1); (b) spawn_enemies
  raises on a bogus id; (c) `["Donu","Deca"]` spawns 2 enemies.

## HIGH — mechanics that silently do nothing / runaway state

### H1. ENTANGLED is a complete no-op (Red Slaver's signature move does nothing)
- `cards.py can_play` correctly blocks ATTACK cards while ENTANGLED — but
  `combat.py _begin_player_turn` **unconditionally deletes ENTANGLED at the start of
  the player's turn**, i.e. before the player can attempt a single card. Applied only
  during the enemy phase → the player never holds it during their own turn.
- **Proof:** forced Entangle → `ENTANGLED present at start of player turn: False`.
- **Fix:** remove the deletion from `_begin_player_turn`; add `PowerId.ENTANGLED` to
  the `tick_down` set in `_tick_player_debuffs`. The existing just_applied guard gives
  exactly the real timing: applied enemy phase N → survives round-N tick → blocks
  attacks all of player turn N+1 → ticks away at end of round N+1. (Keep ENTANGLED in
  `end_combat`'s combat_only cleanup — already there.)
- **Regression test:** enemy applies Entangle → next player turn `can_play` is False
  for ATTACK, True for SKILL → the turn after, attacks playable again.

### H2. BronzeAutomaton spawns 2 fresh Orb Walkers every 6 turns, unbounded
- Pattern index `len(move_history) % 6` → "Spawn" recurs at moves 0, 6, 12, … with
  **no cap and no once-flag** (Collector caps at 4; Automaton has nothing). Each wave
  = +2 stand-in orbs at 80–84 HP. Real game: orbs are spawned **once**.
- **Fix:** spawn once behind a `_spawned_orbs` flag; on repeat "Spawn" slots use
  **Boost** instead (real move: +3 Strength, +9 block to self). Also shrink the
  stand-in orb HP to the real Bronze Orb band 52–58 (`hp_rng.next_int(7) + 52`) —
  80-HP orbs are an act-3-normal-sized add ×2.
- **Regression test:** 13+ simulated rounds → exactly 2 OrbWalkers ever spawned.

### H3. Malleable: over-increments, never resets, triggers on non-attack damage
- `cards.py _apply_damage_to_enemy`: increments the stack **before** granting block →
  first trigger grants **4**, not the base 3. **Proof:** hits 1–5 granted
  4/5/6/7/8 block.
- Never resets: real Malleable resets to base 3 at end of the enemy's turn; here it
  grows monotonically for the whole combat → Writhing Mass becomes ever-tankier.
- Triggers on ANY damage that lands (Combust, Juggernaut, Corpse Explosion);
  real Malleable is **attack damage only**.
- **Fix:** grant `powers[MALLEABLE]` THEN increment; gate on `from_attack=True`;
  reset to base 3 in `_tick_enemy_powers` (store base as a class constant / initial
  value — Writhing Mass starts at 3). Poison already bypasses (direct hp decrement) —
  keep it that way.
- **Regression tests:** first attack hit grants exactly 3; grows within a round;
  resets to 3 after the round ticks; non-attack damage grants nothing.

### M2. 100-turn-draw asymmetry: greedy run continues, LLM run dies
- `run_loop._resolve_combat`: outcome `None` after 100 turns → run **continues**
  (no reward, no death). `benchmark._llm_combat`: timeout → `return False` →
  `_play_act` returns False → **run over**. With a 500-HP GiantHead and 999-HP
  Transient in the pools, stalls are realistic in Acts 2/3 — the asymmetry biases the
  LLM against the greedy anchor.
- **Fix:** make a 100-turn draw a **loss in both paths** (conservative + symmetric):
  `_resolve_combat` sets `result["outcome"] = "loss"` on timeout (keep the
  no-COMBAT_END rule — a draw is still not a win; Burning Blood must not heal).
- **Acceptance criterion (comparability):** re-run `scripts/greedy_baseline.py` for
  BOTH characters and confirm the artifacts are numerically identical to
  `results/greedy_baseline_{ironclad,silent}.json` (Act-1 greedy essentially never
  draws; if numbers move, STOP and escalate rather than re-anchor silently).

### M3. Status cards inserted on TOP of the draw pile instead of the discard pile

  game's discard-pile destination. (TorchHead already appends to discard — correct.)
- Also Act 1, same class of bug, fix together: **Hexaghost Sear** Burn → should be

  `state.rng.misc_rng.next_int(len(draw_pile)+1)`.
- **Regression test:** each of these moves lands its status in the documented pile.

### M4. GiantHead is a 500-HP enemy that deals no damage for 3 turns, then ~15
- "Count" = +1 Str no-damage buff (real Count: **13 damage** attack); "It Is Time"
  starts at 13+2 (real: **30, +5 per use, capped 40**).
- **Fix:** Count = ATTACK 13 dmg (keep 3 uses), It Is Time = `min(40, 30 + 5*(uses-1))`.
  Belongs with its M1 move to the elite pool.

### M5. Chosen has an invented ARTIFACT 1
- Real Chosen has no Artifact. The stack silently eats the player's first debuff
  (Bash Vulnerable, Neutralize Weak, any poison opener) in a common Act-2 fight —
  systematically punishes debuff archetypes, and Silent most.
- **Fix:** remove the Artifact grant.

### M6. Transient: permanently Intangible, unkillable, auto-"win" after 5 turns
- Current: 999+ HP, `INTANGIBLE 1` re-applied every `select_move`, hits
  10×turn-count per turn (blockable), sets `hp = 0` on turn 5 → scored a **win**.
  The fight is decision-free: nothing the agent does changes the outcome except
  block efficiency; it's ~150 damage of pure HP tax that reports as a victory.
  Real Transient has **no Intangible** (Fading + Shifting) and is legitimately
  killable/blockable.
- **Fix:** drop the Intangible (delete both the ctor grant and the select_move
  re-apply); attack = single hit `30 + 10*(turn-1)` (real curve); keep Fading
  (escape at end of its 5th turn via `hp = 0` — fleeing ends the fight as a win,
  matching the real game). Shifting stays unimplemented — add to the
  documented-design list. Also delete the dead identical if/else in `select_move`
  (see L2).

### M7. Maw "Drool" applies an invented CONFUSED
- Real Drool: Maw **gains +5 Strength**. CONFUSED (cost randomization) is a real
  mechanic (Snecko) but not this fight's — it punishes the LLM's cost model in a
  fight where the real game doesn't. Also real Roar is **turn-1 only**; current
  pattern re-applies Vuln 3 + Weak 3 every 4 turns.
- **Fix:** Drool → `+5 STRENGTH` self-buff; Roar → first turn only (then cycle
  Drool/Nom/Nom). Keep Nom at 25 (stand-in for real Slam 25, documented).

### M8. DonuAndDeca Beam hit counts wrong on both bodies
- Donu Beam 10×1, Deca Beam 10×3; real: **both 10×2**, and Deca's Beam adds
  **2 Dazed to the discard pile** (Dazed exists — Sentry uses it).
- **Fix:** hits=2 on both; append 2 Dazed to discard on Deca's Beam.

### M9. `ACT_STRUCTURE` act 3 has 14 floors and an inconsistent boss floor
- `3: (14, 54)` — real Act 3 has 15 content floors like the others, and the
  cumulative boss floor after 16+15 would be 47, not 54. `[1]` is currently unused
  (only `[0]` feeds map gen and the progress denominator), but the wrong value is a
  landmine and the 14 shorts act-3 progress. Pre-data, so free to fix now.
- **Fix:** `3: (15, 47)`.

## Comparability addendum (corrects the header's "ZERO existing data touched")
The header claim needs one caveat the audit under-flagged: **the Hexaghost part of M3
is an Act-1 boss change** (~1/3 of Act-1 boss rolls). Empirically it moved no
published number (greedy anchors identical; death-overkill HP unpublished), and no
prompt bytes changed. But an LLM run-level re-run at the same seeds would see
slightly different Hexaghost fights → this batch is an **instrument-version boundary
for run-level**: the existing matrix's run-level numbers remain valid as-collected;
never blend them with post-batch run-level numbers (M3b runs on the new engine —
which was already the plan; the batch itself is the re-baseline point the header
anticipated).
