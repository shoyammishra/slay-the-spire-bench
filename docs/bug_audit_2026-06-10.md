Full-codebase audit hunting for "the code runs but the results are corrupted" bugs

## Part 1 — COMPLETED fixes (committed this session, 56/56 tests pass)

All verified empirically before fixing; each has a regression test.

1. **Combat `hp_ratio` heal artifact (CRITICAL).** `CombatEvaluator.evaluate` read
   `hp_remaining` AFTER `end_combat()` → COMBAT_END → Burning Blood +6 heal, while
   `_greedy_combat_hp` (the baseline) never emits COMBAT_END. An LLM playing
   IDENTICALLY to the bot scored hp_ratio = **1.095**. The stale pilot ">100% HP vs
   bot" numbers (103.5–113.8%) were this artifact — **never cite "LLM beats bot on
   HP"**. Fixed: HP captured pre-`end_combat` (`hp_at_end` in benchmark.py). Was
   Ironclad-only (Silent starter relic is COMBAT_START) → also a cross-character
   confound. Test: `test_combat_hp_scored_before_combat_end_heal`.

2. **Turn-level oracle wrong for Silent.** `_exhaustive_best_sequence` capped at
   the FIRST 6 playable indices; Silent's 7-card opening hand (Ring of the Snake)
   hit the cap on 6/10 seeds — oracle said 6 when true optimum was 12 (seed 43).
   Rewritten as prefix-pruned DFS over ALL playable cards (identical cards dedup'd
   per node, deterministic 20k-node budget). Verified Ironclad oracle values
   byte-identical to old across seeds 42–49 (comparability preserved); Silent
   seeds 43–49 now match full brute force.
   Test: `test_turn_oracle_handles_more_than_six_playable`.

3. **Multi-seed synergy std was fake.** Fixture choice (`i % 20`) and offer
   rotation (`i % 3`) used the loop index only → `--seeds 42 142 442` sent
   byte-identical prompts (verified) → std=0 by construction. Now keyed on the
   sample's seed (`seed % 20`, `seed % 3`): consecutive seeds still cover every
   fixture once with uniform pick positions; different base seeds give different
   fixture↔rotation pairings. **Side effect:** per-sample pairing differs from the
   saved seed-42 n=20 result files; aggregates stay comparable, rows don't line up.
   Test: `test_synergy_prompts_vary_across_base_seeds`.

4. **Turn prompt never stated the scored objective.** Scorer counts enemy-HP-lost
   only vs a damage-only oracle, but the prompt said "optimal sequence" — models
   were penalized for unscored defensive/setup play (Bash-first, Defend). System
   prompt now says: maximize total damage THIS TURN, defense NOT scored, illegal
   card zeroes the answer. **Turn scores not comparable across this change** (they
   were already stale). Test: `test_turn_prompt_states_damage_objective`.

5. **Intent display showed base damage.** Cultist showed "6 dmg" forever while
   Ritual grew real hits 9/12/15; real StS shows adjusted values. Added
   `effective_move_damage(enemy, move)` in enemies.py — single source of truth
   used by `_enemy_attack` AND both prompt formats (Strength + Weak adjusted).
   Also fixed **RedLouse Strength double-count** (baked into Move at select time
   AND added again by `_enemy_attack` → Bite dealt 11 not 8 after one Grow).
   Tests: `test_intent_shows_effective_damage`, `test_red_louse_strength_not_double_counted`.

6. **Fixture-confidence test gap closed.** `test_synergy_fixture_ground_truth_rules`
   now asserts all 40 fixture decks classify CONFIDENTLY as their declared archetype
   (the scoring-time label comes from the classifier, not the fixture tag).

Also verified clean during the audit (no action needed): all 40 synergy fixtures
classify correctly; boss relic pool IDs all resolve in the registry ("Slaver's
Collar" etc.); removal scoring has NO string-format near-misses in saved results
(wrong answers are genuinely different cards, mostly "Defend"); `Sundial2` is dead
code NOT in any pool (the SHUFFLE-fixed Sundial is the registered one).

## Part 3 — bugs found in the quick pass over previously-unread files (ALL FIXED 2026-06-11)

The pass over `events_pool.py`, `potions.py`, `enemies_act2.py`, and the
`cards.py`/`cards_silent.py` implementations found 8 more, two of them serious
engine bugs affecting EVERY combat:

1. **Vanishing played cards (CRITICAL).** `Card` is a `@dataclass` → field-based
   `__eq__`. `play_card`'s `card not in combat.hand` check was True whenever an
   IDENTICAL copy was still in hand (5 Strikes / 4 Defends in the starter deck!),
   so the played copy was never appended to the discard pile — it vanished from
   the combat for good. Decks silently shrank every turn a duplicate was held.
   Same eq-vs-identity bug in `play_card`'s hand removal, `_exhaust_card`, and
   `_discard_from_hand` (could remove/duplicate a twin instead of the actual
   card). Fixed with identity-based `_remove_identical()` + identity membership
   checks. Test: `test_played_card_with_twin_does_not_vanish`. **Combat dynamics
   change — pre-fix combat numbers were already stale, now doubly so.**
2. **Double exhaust.** Self-exhausting cards (31 callsites: Slimed, Disarm, Blood
   for Blood, Reaper, …) were appended to the exhaust pile a SECOND time by
   `play_card`'s exhaust branch, double-emitting CARD_EXHAUST → Feel No Pain /
   Dark Embrace / Dead Branch triggered twice per card.
   Test: `test_self_exhausting_card_exhausts_once`.
3. **Blood for Blood double energy charge** — `play()` deducted its cost on top
   of `play_card()`'s payment (the same class as the old 63-line double-charge
   sweep; this card was missed because of its custom `effective_cost`). Its
   `_times_hit` discount was also a dead flag (never incremented) — now wired in
   `_damage_player`. Test: `test_blood_for_blood_energy_and_discount`.
4. **Hand-limit bypass** — Infernal Blade, Power Through, Dual Wield, Exhume, and
   Pride appended directly to `combat.hand` instead of `_add_card_to_hand`
   (10-card limit + overflow-to-discard).
5. **Neow "1 HP" boon was a dead flag** — `_neow_1hp_combats` was written, never
   read. Now consumed in `start_combat`.
6. **Winged Statue always dealt 0** — `player._cards_removed` was read but never
   incremented. Now counted in shop removal, Peace Pipe toke, and event removals.
7. **Transmogrifier gave Silent runs Ironclad cards** — `_transform_card` used
   `_IRONCLAD_POOL`/`make_card` directly; now `card_pool_for`/`make_card_for`.
8. **Council of Ghosts charged half HP for nothing** (auto-pick takes choice 0!)
   — Apparitions were flavor text. Implemented the `Apparition` card (1-cost
   skill, gain 1 Intangible, Ethereal, Exhaust) and 5 copies are now added.
9. *(crash, latent)* **Event HP loss between combats crashed Centennial Puzzle /
   Runic Cube** — their DAMAGE_TAKEN handlers (still subscribed from the previous
   combat) called `_draw_cards` with `state.combat is None`. Guarded.

Verified clean in the same pass: `enemies_act2.py` has NO baked-Strength bugs (all
buffs go through `powers`, consumed by `effective_move_damage` at execution) and no
direct `player.hp` writes; `cards_silent.py` has no direct hand appends and no
energy double-charges; `potions.py` issues (Ironclad pools, unregistered Fairy)
are moot under the accepted "potions never drunk" limitation (2.10).
