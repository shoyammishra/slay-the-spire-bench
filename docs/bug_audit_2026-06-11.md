## A. Instrument bugs (fix BEFORE any paid runs)

### A1. Turn-eval duplicate-index loophole — VERIFIED
`_simulate_play_sequence` (benchmark.py) checks `if card not in c.hand` with dataclass
`__eq__`, and `play_card` both checks membership by equality AND ignores
`_remove_identical`'s return value. Net effect: a model answer like `"plays": [2, 2]`
replays an already-played card as long as an identical twin is still in hand — scored
**legal**, full damage counted (repro: `[2,2]` = 12 dmg, legal=True, identical to the
honest `[2,3]`). Worse, the second play does NOT remove the twin from hand, so
hand-counting cards can *beat the legal optimum*: e.g. hand `[Fiend Fire, Strike,
Strike]`, `plays [1,1,0]` leaves Strike#2 in hand for Fiend Fire to exhaust (+6) vs
the honest `[1,2,0]`. `damage_ratio` is capped at 1.0, so this inflates weak models
toward the cap and can mask illegal-play behaviour.
**Fix:** track played indices (reject repeats) + identity-based hand membership in
both `_simulate_play_sequence` and `play_card` (make `play_card` raise when
`_remove_identical` returns False).

### A2. Oracle has the same equality-membership hole — [static]
`_exhaustive_best_sequence` guards with `card not in s.combat.hand` (equality). A card
removed from hand by a side effect (auto-discard from Survivor/Acrobatics, exhaust by
Fiend Fire/Second Wind/Sever Soul) still passes the guard when a twin remains, and
`play_card` then accepts it (same root cause). The oracle can therefore count damage
from sequences that are not actually legal → **overstated optimum → deflated
turn-level scores**, mainly for Silent (discard package). Same fix as A1.

### A3. Neow's Lament sits in the mid-run event pool — VERIFIED
`events_pool.py` registers Neow with `acts=[1]` and no exclusion, and
`random_event()` can roll it on any Act-1 EVENT node. The run loop auto-picks
choice 0 = **"enemies in your first 3 combats have 1 HP"** → any event floor has a
~1/N chance of trivialising the next 3 combats, directly inflating run-level
survival/HP. (Related free-lunch: Mind Bloom choice 0 grants +100 gold with the
"fight Act 1 boss" not implemented.)
**Fix:** drop Neow from `EVENT_REGISTRY` (or gate `floor == 0`), and make
unimplemented-fight choices cost-only or remove them.

## B. Engine bugs — combat-dynamics-changing

> ⚠️ B1 and B2 both change combat numbers again — re-baseline turn/combat after fixing.

### B1. HP-loss effects are absorbed by block — VERIFIED
`_damage_player` applies block (`blocked = min(block, amount)`) **before** the
`is_hp_loss` branch. Real StS: HP loss bypasses block entirely. Affected: Offering,
Bloodletting, Hemokinesis, Combust self-damage, Brutality, Burn/Decay/Regret
end-of-turn, **player Poison ticks** (poison ticks at TURN_END while the turn's block
is still up — so block largely neutralises poison vs the player), Pain, Blue Candle.
Repro: block 10, Offering's lose-6 → HP unchanged, block 10→4.
(The CLAUDE.md note "poison bypasses block" is true only for the *enemy*-side tick.)
**Fix:** skip the block step when `is_hp_loss=True`.

### B2. Havoc duplicates the top draw-pile card — VERIFIED
`Havoc.play` plays `draw_pile[-1]` **without removing it from the draw pile**, then
`_exhaust_card` (which only removes from hand) appends it to the exhaust pile. The
same object now lives in BOTH piles; deck count 10→11; CARD_EXHAUST fires
(Feel No Pain/Dark Embrace credit) while the card is still drawable.
**Fix:** `draw_pile.pop()` before playing.

### B3. Warcry / Setup equality-`remove` duplication — VERIFIED (Warcry)
`Warcry.play` does `hand.remove(card)` (dataclass `__eq__`) then appends `card` to
the draw pile — when a twin precedes it in hand, the twin is removed and the chosen
object ends up in hand AND draw pile (repro: 1 object in both). `Setup.play`
(cards_silent.py) has the identical shape. Same family as the Part-3 vanishing-card
fix; these two call sites were missed. The ethereal/discard loop in
`end_player_turn` also uses equality `remove` (benign today, same class).
**Fix:** use `_remove_identical`.

### B4. Corruption never makes skills free for legality — VERIFIED
`Card.can_play` ignores `player.corruption`, so a mid-combat Corruption leaves skills
playable only if their printed cost is affordable (play_card would charge 0, but
can_play blocks it at the gate). The `start_combat` cost_override-zeroing branch is
dead code — `end_combat` always clears `corruption`, so it can never be true at
combat start.
**Fix:** in `can_play`, treat skills as cost 0 under corruption; delete the dead
start_combat branch.

### B5. Searing Blow damage formula wrong — VERIFIED
`(n² + 7n + 12)//2 + (n%2)` gives 6 base / 11 at +1. Real: `n(n+7)/2 + 12` → 12 / 16.
Halves the card's damage at every upgrade level.

### B6. Reaper heal mis-computed — VERIFIED
Heals `dmg - post-hit block` per enemy (block already consumed by the hit) and
ignores Strength/Weak. Repro: 1 unblocked damage dealt, 4 HP healed. Two dead local
variables (`dealt`, `actual`) in the same block.
**Fix:** heal `hp_before - hp_after` per enemy.

### B7. Choke never expires — VERIFIED
`PowerId.CHOKED` is applied by Choke and ticked by the CARD_PLAY hook forever; real
StS Choke only lasts the turn it was played. Nothing ever removes the power.

### B8. Finisher counts itself — VERIFIED
`attacks_played_this_turn` is incremented in `play_card` *before* `card.play()`
executes, so Finisher as the first attack deals 6 (real: 0). Every Finisher hits one
extra time.

### B9. Blood for Blood: wrongly exhausts + upgrade keeps cost 4 — VERIFIED
Real BfB does not exhaust, and BfB+ costs 3 base. Here `exhaust=True` (+ explicit
`_exhaust_card`) and `upgrade()` never lowers `cost`.

### B10. Perfected Strike excludes itself — VERIFIED
During play the card is in no pile (removed from hand, not yet discarded), so the
strike count misses its own "Perfected Strike" id → −2 (−3 upgraded) damage every
play. Repro: 14 dealt where real is 16.

### B11. Escape Plan misses the drawn card via equality — VERIFIED
`drawn = [c for c in hand if c not in before]` — when the drawn skill equals a card
already in hand (e.g. a second Defend), `drawn` is empty and the block is skipped.
**Fix:** identity comparison (or compare hand length / take the appended object).

## C. Relic / enemy fidelity bugs

### C1. Snecko Skull poisons the PLAYER — VERIFIED
`on_turn_end: if POISON in player.powers: player.powers[POISON] += 1`. That makes the
Silent-only relic actively harmful (sustains poison on the player). Real effect:
+1 poison whenever **you apply poison to an enemy**.
**Fix:** hook poison application (e.g. flag checked in `_apply_power`).

### C2. Blue Candle is a no-op — VERIFIED
Curses have `unplayable=True`/`can_play()=False`, and Blue Candle only subscribes to
CARD_PLAY — which can never fire for a curse. Real relic makes curses playable
(lose 1 HP, exhaust). **Fix:** `can_play` honors a `_blue_candle` flag.

### C3. Pandora's Box transforms every *Strike*-named card — VERIFIED
Matches `"strike" in c.id.lower()` → Twin/Perfected/Pommel/Wild/Sneaky/Poisoned(no)
Strikes are all swapped, not just basics (repro: all 3 non-basic strikes removed).
**Fix:** exact ids `Strike_R/Strike_G/Defend_R/Defend_G`.

### C4. Fairy in a Bottle never registers — [static]
`Potion.register` exists only on Fairy, but no code path registers potions on the bus
(only relics register at combat start). The auto-revive can never fire.

### C5. Potions are never drinkable — [static]
No caller of `Potion.use()` anywhere; `POTION_USED` is never emitted (Toy Ornithopter
dead). Greedy and LLM policies only *collect* potions. If this is by design, document
it (it silently devalues Alchemize/White Beast Statue/Sozu trade-offs and the potions
the LLM "earns"); Power/Skill Potion also use `_IRONCLAD_POOL` unconditionally —
character leak if drinking is ever wired.

### C6. Lagavulin's Metallicize never fires — [static]
`_tick_enemy_powers` handles only RITUAL/REGENERATE/POISON; enemy METALLICIZE (8) has
no handler, so sleeping Lagavulin gains no block (much easier than real).

### C7. Time Eater's Time Warp never fires — [static]
`TimeEater.check_time_warp` ("extra turn every 12 cards") is defined but has zero
callers. The Act-3 boss's signature mechanic is absent (and the stub itself only adds
block, which is also wrong).

### C8. Acid Slime M/L Corrosive Spit applies Weak instead of Slimed — [static]
Real Corrosive Spit deals damage and shuffles 1–2 Slimed into the discard pile (the
Spike Slimes do this correctly); Acid Slimes instead apply Weak 2/3 on top of their
separate Lick move.

### C9. Slime Boss split children get fresh HP — [static]
`SlimeBoss.on_hp_threshold` spawns SpikeSlimeL/AcidSlimeL with their own RNG HP
(65–74) instead of the boss's current HP. The L-slimes' own splits DO inherit
(`m.hp = m.max_hp = self.hp`) — inconsistent within the same file.

## D. Minor / edge findings

- **D1. Combust HP-loss fixed at 1** regardless of stacks (real: 1 per Combust
  played). powers.py TURN_END hook.
- **D2. Thorns→player damage amplified by player Vulnerable** (`_damage_player`
  applies Vuln to all non-hp-loss damage; Vuln should only affect *attacks*).
- **D3. Bullet Time's `cost_override=0` leaks** if the card is exhausted that turn
  (end-of-turn restore loop scans hand+discard+draw only) → Exhumed copy costs 0
  forever.
- **D4. Mummified Hand's cost_override is permanent** (real: until played). Noted as
  simplification but undocumented.
- **D5. Hexaghost Divider is H//12, real H//12+1**; Sear/Divider Burn placement
  approximations (draw-pile bottom vs discard).
- **D6. run_loop `_resolve_combat` 100-turn draw** leaves `state.combat` set (no
  end_combat) — stale-combat edge for between-combat guards (`gs.combat is None`).
  `_llm_combat` cleans up; the greedy loop doesn't.
- **D7. `random_relic` fallback**: when every pool relic is owned/filtered, falls back
  to the FULL registry including off-class relics.
- **D8. Boss-relic LLM pick not counted in `llm_calls`** (`_act_transition` doesn't
  pass counters). Metric undercount only.
- **D9. `VoidCard.on_draw` is dead code** (engine calls `on_drawn`; the energy loss is
  handled by the CARD_DRAW hook via classname) — works, but the method is misleading.
- **D10. Events repeat within a run** (`available_events` has no seen-set) and
  rest-smith policy can target curses (CurseBase.upgrade is a no-op `pass`, so
  Armaments/auto-smith can waste upgrades on curses; Armaments+ "upgrades" statuses).
- **D11. Gambler's Brew bypasses discard triggers** (`discarded_this_turn`,
  CARD_DISCARD, Reflex/Tactician) — moot while potions are undrinkable (C5).
- **D12. GremlinNob `ANGER_ENEMY` line is a no-op** (`powers[ANGER] = get(ANGER, 0)`);
  the real mechanic uses the separate `"enrage"` string key. Cosmetic.
- **D13. `_nloths_trade` body checks `>= 2` relics while the event condition requires
  `>= 3`** — harmless inconsistency.
- **D14. String power keys** (`"Calm"`, `"enrage"`) mix with PowerId in `powers`
  dicts; prompt builders handle them (`hasattr(k,'value')`) but any future
  `.value`-assuming consumer will crash. Convention risk.

## Fix implementation notes (2026-06-11)
- **A1/A2/B3 family:** `play_card` now uses IDENTITY hand membership and raises
  if `_remove_identical` fails; `_simulate_play_sequence` rejects repeated
  indices and uses identity membership; the oracle uses identity membership;
  Warcry/Setup/`end_player_turn` use `_remove_identical`.
- **A3:** Neow gated to `player.floor == 0` (events fire at floor ≥ 1, so it is
  out of the mid-run pool but still available for explicit run-start use);
  Mind Bloom "I am War" no longer grants unearned gold; events no longer repeat
  within a run (`state._seen_events`).
- **B1:** `_damage_player(is_hp_loss=True)` bypasses block/Intangible/Vulnerable;
  new `from_attack=False` mode for non-attack damage (Thorns retaliation,
  Burn/Decay — blockable, Intangible-capped, no Vulnerable; also fixes D2).
- **B2:** Havoc pops the top card before playing it.
- **B4:** `can_play` zeroes skill costs under Corruption; dead `start_combat`
  branch removed.
- **B5–B11:** card-local fixes as specced (B9: BfB cost `3 if upgraded else 4`,
  no exhaust; B7: CHOKED popped from all enemies at end of player turn; B8:
  `attacks_played_this_turn` incremented AFTER the card resolves).
- **B12 (new, see status box):** enemy block resets at enemy-phase start, not
  player-turn start.
- **C1:** `_snecko_skull` flag consumed in `_apply_power` (+1 poison applied to
  enemies). **C2:** `_blue_candle` flag honored in `can_play`; `play_card`
  clamps cost to ≥ 0 (a curse's −1 cost used to be a path to +1 energy).
  **C3:** Pandora's Box matches exact basic ids. **C4:** `start_combat`
  registers potion hooks (Fairy in a Bottle works). **C5:** potions remain
  undrinkable by policy — documented design simplification (Gambler's Brew
  now routes through `_discard_from_hand` for whenever drinking is wired).
  **C6:** enemy METALLICIZE ticks block in `_tick_enemy_powers` (+ Lagavulin
  drops it on wake). **C7:** Time Warp implemented in the engine: every 12th
  card play sets `combat.time_warp_lock` (blocks further plays ≈ ends the
  turn) and grants the boss +2 Strength; dead `check_time_warp` deleted.
  **C8:** Acid Slime M/L Corrosive Spit adds 1/2 Slimed (Weak stays on Lick).
  **C9:** Slime Boss split children inherit its current HP.
- **D:** D1 (`_combust_plays` counter, reset each combat), D3 (Bullet Time
  restore includes exhaust pile), D5 (Divider `hp//12 + 1`), D6 (run_loop
  clears stale combat on a 100-turn draw, no COMBAT_END), D7 (staged
  `random_relic` fallback: fresh → allowed → raw pool), D8 (boss-relic pick
  counted in `llm_calls`), D9 (dead `VoidCard.on_draw` removed), D10 (smith +
  Armaments skip curses/statuses; event seen-set), D11 (Gambler's Brew),
  D12 (dead Nob line), D13 (N'loth body matches condition).
  D4/D14 intentionally not changed.

⚠️ B1+B2+B12 change combat dynamics — re-baseline turn/combat before collecting
paid numbers. Synergy n=20 results remain valid (no synergy-path bug found in
this audit).
