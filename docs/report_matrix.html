0 · Executive summary

Planning skill is not one number

We decomposed LLM planning into four nested horizons inside one game engine and measured seven model configurations against per-horizon references. The result: model differences are large at the reasoning horizons and vanish at the survival horizons. Turn-level optimality spans 0.18–0.84 and deck-strategy identification 0.33–0.80 across models — yet at combat and full-run level, every instruct model converges onto the same floor as a scripted greedy bot. A whole-game score would have compressed all of this into indistinguishable aggregates.

Three secondary results, each individually citable: (a) reasoning-tuned models are not a free win — the best short-horizon model (DeepSeek-R1-14B) over-deliberates itself to death at long horizons, finishing below the greedy baseline; (b) larger Qwen3 capacity selectively improves card choice rather than every horizon; (c) models identify strategies defined by surface card-text patterns at ~0.81 but strategies defined by a payoff mechanic at 0.02–0.14 — below even 4-way chance — while still picking good cards for those same decks above chance (name-vs-play dissociation, confirming Bateni & Whitehead, FDG 2024).

The one-sentence ask

The benchmark and open-model matrix are complete; the headline claim — planning capability decomposes by operation rather than model label or scale — now includes complete Qwen3-32B and Qwen3-235B matrices. One frontier model (Claude or GPT), run through the identical harness on the identical seeds, is the decisive experiment — and either outcome completes the paper (§7).

1 · What slay-bench measures

Four horizons, one simulator, four oracles

slay-bench is a faithful Python re-implementation of Slay the Spire (two characters: Ironclad and Silent) plus a benchmark harness. Unlike whole-game benchmarks that report one score per game, it isolates four planning horizons inside the same domain, each scored against its own ground truth — so a score difference between horizons isolates a planning-horizon effect, not a domain shift.

#DimensionHorizonWhat it testsGround truth
1Turn-level~6 cards, 1 turnOptimal card sequencingExhaustive search over all legal sequences (provable optimum)
2Combat-level~5–10 turnsReactive tactics under HP pressureScripted greedy-bot baseline
3Synergydeck snapshotStrategy ID and best pick40 hand-crafted archetype decks (20/character), expert-labeled; removal-v1 quarantined
4Run-level15 floors (full act)Long-horizon resource allocationMeasured greedy survival floor (same seeds, same engine)

Every model sees every task in two prompt formats — compact structured JSON and verbose natural English — generated from identical RNG seeds, giving a clean representation ablation. The harness is deliberately unscaffolded and memory-free: it measures the floor of raw per-horizon planning. This is the designed complement to Anthropic's use of Slay the Spire in their Claude Fable 5 launch evaluation, which measures the ceiling of an engineered agent with memory and vision — external validation that this game is an accepted frontier-lab planning testbed, not an idiosyncratic pick.

2 · Why the numbers can be trusted

Instrument first, measurement second

Every number below survived a policy of treating the instrument as guilty until audited:

  • Five adversarial audits of the engine and harness (≈130 bugs found and fixed before the paper-grade runs), including instrument biases that flattered the models — e.g. a relic heal inflating combat HP ratios by ~10%, a positional bias worth up to 40 points of card-pick accuracy, and a replay loophole that let models beat the "exhaustive" oracle. 174 regression tests now pin the fixes.
  • Baselines are measured, not assumed. The greedy run floor was measured empirically on the matrix's exact seeds (n = 20 × 5 bases per character): Ironclad 12.48 floors / 0.780 progress / 1% survival; Silent 11.26 / 0.704 / 0%. All normalization is anchored per character to these numbers.
  • Boundary values were audited per-sample. The two boundary results that remain (instruct models' 100% combat wins; a format-collapse where one model answers a constant label) were verified in the raw per-sample JSON to be genuine model behavior, not harness artifacts.
  • Degenerate-strategy audit: removal-v1 failed because all 40 expert targets were Strike; an always-Strike model scores 100%. We preserve the raw field but exclude it from claims, statistics, and the synergy composite.
  • Comparability discipline: all 28 canonical aggregates use the frozen instrument; no result tier is silently blended. Qwen3 run rows remain descriptive N_RUN=5 floor estimates.

5 · Findings

Five results, in the order the paper will make them

1

Discriminating power lives at the reasoning horizons; the survival horizons are a shared floor.

Across the matrix, turn-level optimality spans 0.18→0.84 and archetype identification 0.33→0.80 — yet every instruct model wins ~100% of combats at greedy-equivalent HP and reaches greedy-equivalent run floors. Model quality is invisible to whole-game survival metrics on this horizon; a benchmark that only reported win/loss would have flattened much of this matrix. This is the multi-horizon thesis in one result.

2

Run-level is honestly a convergence floor — reported as such, not as a discriminator.

All instruct models land within noise of the measured greedy floor (Ironclad 12.7–13.8 vs greedy 12.48 floors; Silent 10.9–11.9 vs greedy 11.26) — on par, never beating it (largest normalized lift ≤ 0.13). The only deviations point downward (finding 3). External corroboration: Anthropic's scaffolded Fable 5 agent reached the final act only ~3× more often with memory than without — full-run survival is a severe bottleneck even at frontier scale. We therefore report run-level as the shared collapse floor and let the separation land at turn + synergy, rather than spending ~72–144 GPU-hours making the run longer to likely confirm a deeper floor (a registered, conditional multi-act probe exists for after the frontier runs).

3

Reasoning and capacity are operation-selective, not free wins.

DeepSeek-R1-14B is the best model at the shortest horizon on both characters (turn 0.82 / 0.84) yet the only mid-size model that loses combats (down to win 0.34, hp 0.21 on Silent-raw) and the only model to fall below the greedy run floor (9.8 vs 12.48 floors): its verbose deliberation literally over-thinks itself to death as the horizon lengthens. Its 7B sibling collapses at every execution horizon; a follow-up probe attributes all observed true JSON failures to token-budget truncation mid-reasoning. Conversely, Qwen3-235B improves best-pick accuracy over Qwen3-32B by .110–.280 in all four cells and 19/20 seed pairs, while turn, combat, and run effects stay mixed or saturated. Together: model label and capacity do not move every planning operation together.

4

Prompt format depends on the operation and model.

With identical seeds across 14 model×character strata, structured JSON has a general combat-HP advantage (+.059 pooled; 12/14 directions), while turn directions split 6/8 and valid synergy effects are model-dependent. Cleanest single illustration: in raw format, Qwen2.5's archetype answers collapse to a constant "Block" guess — 17 of 20 decks, every seed, verified per-sample with perfect parse rates — scoring exactly the base rate of its guess, while the same model on the same decks in structured JSON spreads its answers and scores higher. Verbose English drowns the signal; compact state forces the model to read the deck.

5

Models can play strategies they cannot name — and the blind spot is mechanistic, replicated across characters.

Pooled over all 2,800 synergy samples in the matrix (7 configurations × 2 characters × 2 formats × 5 seeds; recomputed from the per-sample records for this report): archetypes with surface card-text signatures are identified reliably — Block 0.82, Poison 0.84 — while the two archetypes defined by a payoff mechanic, Ironclad Exhaust and Silent Discard, score 0.02 and 0.22: at or below the 0.25 four-way chance floor. Yet on those same unlabelable decks, best-card-pick accuracy holds at 0.43 against a 0.33 chance floor — local card-quality judgment survives where abstract strategy naming fails. This confirms and quantifies, across formats and models, the name-vs-content dissociation Bateni & Whitehead (FDG 2024) first observed via card-name randomization — we frame it as extending their result, not discovering it.

6 · Honest caveats & limitations

What this data can and cannot claim

  • Removal-v1 is quarantined. Every expert target is Strike, so constant Strike scores 100%. The diagnostic column is retained only for artifact transparency; no strategic pruning or format claim is made from it.
  • Qwen3 run rows use N_RUN=5 per seed and are descriptive floor estimates, never pooled with the balanced N_RUN=20 variance analysis.
  • Qwen3-235B is a 22B-active FP8 MoE while Qwen3-32B is dense; their comparison is within-family capacity evidence, not a pure parameter-scaling law.
  • DeepSeek-7B synergy accuracies are conditioned on its parse rate (0.69–0.92 → ~14–18 of 20 fixtures scored). Stated wherever those cells are cited.
  • The combat point is a plateau, not a collapse, for instruct models — Act 1 is winnable by greedy play, so the combat baseline is a near-ceiling by construction. The curve renders this honestly rather than forcing a monotone descent.
  • "—" cells are intentional, not missing: DeepSeek run-level was skipped after its collapse was established; Qwen3-32B and Qwen3-235B now have all four dimensions.
  • Single domain. Mitigated, not removed, by two characters inside one engine and by framing the contribution as a reusable decomposition method. Prior STS work exists and is cited preemptively (Bateni & Whitehead FDG 2024; the Orak multi-game benchmark includes STS) — our novelty is the per-horizon oracle decomposition, optimality-relative scoring, and the seed-matched format ablation, none of which prior STS or game benchmarks provide.
  • Floor, not ceiling. No memory, no scaffolding, no retries — by design (it keeps every horizon independently scorable and deterministic). Scaffolded variants are future work.

7 · The missing experiment

One frontier model completes the paper — this is the ask

Everything above is done, audited, and documented. The single remaining gap between "strong open-model study" and a broader capability claim is one experiment: a frontier model (Claude or GPT) through the identical harness, identical seeds, all four horizon × format combinations.

Why it is decisive — either way

  • If the frontier line separates (holds high through synergy, possibly holds combat without the DeepSeek crash): that is the headline result — the collapse horizon moves with capability — and the curve in §3 was built to show exactly this.
  • If the frontier model also floors at run level: that is a strong, publishable negative — raw per-horizon planning hits the same wall regardless of scale (consistent with Anthropic's memory-dependence observation) — and it triggers our pre-registered single-cell multi-act probe (one model, ~12 h) as the appendix test of whether longer horizons separate or deepen the floor.

What it costs

  • Engineering: negligible. The harness already speaks any OpenAI-compatible API; adding an Anthropic/OpenAI provider class is a small, tested change. Seeds, fixtures, oracles, and the figure pipeline are frozen — new aggregates drop into the existing plots automatically.
  • Compute: API credits only. The expensive dimensions are known from measured token counts; we would run the proven cheapest-first order (smoke → turn/combat → synergy → run) with the same partial-save protections used on the cluster.

Venue positioning (honest)

  • As-is today: workshop-strong (NeurIPS/ICLR workshop, FDG, IEEE COG). The D&B-blocking review gaps that could be closed with open models have been closed: ≥3 families ✅, reasoning model ✅, n = 20 × 5 seeds ✅, valid run-level data ✅, second character ✅, horizon curve ✅.
  • With the frontier runs: a defensible NeurIPS Datasets & Benchmarks / ICLR submission — the open-model selective-capability result gains a genuinely frontier-scale test.
